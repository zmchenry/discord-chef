# Chef v1

v0 shipped 2026-11-16 (see `chef.md`). v1 is built by feature owners in parallel, each
on its own branch with its own migration number, then merged and deployed together.

| Owner | Feature | Migration | Status |
|---|---|---|---|
| Nutrition | Weekly macros (estimated per ingredient), goals for Zach and Liz, per-meal portion split | 0009 | building |
| Pantry | "Already have it": on-hand ingredients go to an "Already have" group, out of totals; check-off marks on hand; "Used it up" | 0010 | building |

| Recipe experience | Cooking mode (large type, screen stays on, step timers) + re-import a link into an existing recipe | none | building |
| Discovery | Ideas inbox: new web recipes for a theme or "like this recipe"; hook in Plan dinners | 0012 | building |
| Walmart (spike) | Research only: can Chef fill a Walmart cart? Verdict before any build | none | researching |
| Lead | "Save changes" when a finished week is edited; README; retire the bot; section fixes; v0 → `main` | 0013 | done |

Rules carried over from v0: 80/20 (personal app, small tests that catch real breakage),
one primary action per screen with the rest under ⋯, the standard Modal, true-neutral
palette backgrounds, Claude Haiku 5.5 for all AI calls, no personal data in this public
repo.

Data work running alongside: drafted ingredient lists for the ~52 recipes that have
none, reviewed by Zach and Liz on a review page, then imported.
